- **오른쪽 위 돋보기**: 화면에 없는 말로도 찾아 주는 검색(예: "괄사", "쓰레기", "콘센트"). 결과를 누르면 그 화면으로 이동합니다.

## 수정하는 법 — `CONFIG` 한 곳만 고치면 됩니다

두 가이드는 **같은 구조**입니다. `arn/index.html`·`jamsil/index.html` 안의

```js
var CONFIG = { stay: {...}, pages: {...}, ... };
```

가 모든 글자·사진·버튼을 담고 있습니다. 글자는 네 언어를 함께 씁니다.

```js
T("한국어", "English", "日本語", "中文")
{ ko: "한국어", en: "English", ja: "日本語", zh: "中文" }
```

- 화면 하나 = `pages` 안의 `{ title, sub, back, tab, blocks }`. `back`은 뒤로 버튼이 갈 화면입니다.
- `blocks`에 쓸 수 있는 것: `text`(문단) · `note`(강조 상자, `tone:"accent"|"soft"`) · `steps`(번호 단계) · `photos`(사진, `cap:true`면 설명, `zoom:true`면 눌러서 크게) · `facts`(표) · `heading`(소제목) · `address`(주소·복사·지도·택시 버튼) · `wifi`(와이파이 한 개) · `wifiList`(층별 여러 개) · `kakaot` · `uber` · `points`(점 목록) · `links`(다른 화면 버튼) · `spots`(맛집 카드) · `course`(코스 정류장) · `xplist`(체험 카드+필터) · `rows`(한 줄 목록, 4번째에 전화번호를 넣으면 전화 걸기) · `faq`(펼치는 질문) · `numbers`(119·112·1330) · `hostcard` · `call` · `msgbtns` · `linkcard`(바깥 링크 버튼).
- **블록을 새로 만들거나 고칠 때**는 같은 파일 아래쪽 `<script>`(공용 앱 코드)의 `var R = { ... }`에 그리는 방법이 있습니다. 두 파일에 같은 코드가 들어 있으니 함께 고쳐 주세요.

### `_build/v2/` 에서 다시 만들기 (선택)

- `style.css` — 두 가이드가 함께 쓰는 디자인(강조색은 `--accent`, 연한 배경은 `--tint`).
- `app.js` — 화면 그리기·검색·사진 크게 보기·언어 전환·날씨.
- `content_arn.py` · `content_jamsil.py` — 내용(네 언어). 기존 페이지에서 뽑아 둔 번역 사전(`_ref/`)을 그대로 쓰는 부분이 있어 문구가 서로 어긋나지 않습니다.
- `build_v2.py` — 위 셋을 합쳐 `arn/index.html`·`jamsil/index.html`을 만듭니다.
- `check_render.py` — (개발용) 브라우저로 열어 화면·언어를 확인합니다. 이 작업 환경에서는 chromium 라이브러리가 없어 실행되지 않았고, 실제 확인은 배포 주소에서 했습니다.

```sh
python3 stay-arn/guides/_build/v2/build_v2.py      # 두 숙소 모두 다시 만들기
python3 stay-arn/guides/_check_guides.py           # 검사
```

> `_build/`, `_ref/`, `_notion/`, `previews/`, `_check_guides.py`, `_render_check.py`, `_deploy.sh` 는 GitHub Pages에 올리지 않습니다.
