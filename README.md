## 2026-11-22 개편 — 디자인 기준과 새 섹션

미강님 요청으로 세 페이지를 [asanstay.com](https://www.asanstay.com/)의 Moment Seoul 상세 페이지(https://momentseoul.vercel.app/) UI/UX로 다시 잡았습니다.

- **디자인**: 크림 바탕(`#fbf8f2`) + 흰 카드 + 얇은 베이지 테두리(`#ece4d5`) + 둥근 모서리(18~24px), 큰 제목과 넉넉한 여백. 색은 아른 딥 틸(`#14675a`), 잠실 웜 코퍼(`#a8663a`).
- **히어로**: 사진 위를 아래로 갈수록 배경색으로 흘려보내는 그라데이션(`.hero-media::after`) + 제목·소개·메타 칩.
- **상황 카드(`.stages`)**: "지금 어떤 상황이세요?" — 체크인 전 / 머무는 동안 / 주변 / 도움이 필요할 때. 아른은 3개(마지막 카드가 가로 전체), 잠실은 4개(2×2).
- **목차(`.nav` > `.chip`)**: 가로 스크롤 칩. 좁은 화면에서는 헤더 아래에 붙어 따라오고(sticky), 900px 이상에서는 줄바꿈되어 고정되지 않습니다.
- **아코디언(`details.fold`)**: 집 사용 안내(주방·거실·조명·보일러), 회의실(빔프로젝터), 잠실 시설·가전(온수·세탁기·소파베드·에어컨), 괄사 사용법 6단계.
- **자주 묻는 질문(`.faq`)**: `details` 한 줄짜리 질문 + 펼침. 두 숙소 각 14문항.
- **맛집 & 체험(잠실)**: Moment Seoul 안내를 그대로 옮겼습니다. 20곳 + 추천 코스 2개 + 서울 인기 체험 10선. 문구는 `jamsil/index.html` 안 `var G = [...]`(맛집), `var C = [...]`(코스), `var XP = [...]`(체험)에 4개 국어로 함께 들어 있고, 언어를 바꾸면 다시 그립니다.
- **괄사 사용법(아른)**: 원본 노션 `Gua Sha Welcome Guide`(333d8f74-3856-808c-b7ab-e0d43619d8c2)를 6단계로 옮기고 사진 5장을 `arn/images/guasha-*.jpg`로 받아 넣었습니다. 아래 '원본 가이드 전체 보기'로 노션 링크도 남겼습니다.
- 통합 메인에서 **"두 숙소 합쳐 20인" 문구는 삭제**했습니다(4개 국어 사전에서도 제거).

## 수정할 때

  한 문구를 고치면 한국어(HTML)와 세 언어(사전)를 함께 고쳐 주세요.

- 검사: `python3 stay-arn/guides/_check_guides.py`
  → 세 파일(`index.html`·`arn/`·`jamsil/`)의 HTML 태그 짝, JS 문법, 4개 국어 문구 누락, 본문 내 4자리 비밀번호 노출 여부를 확인합니다.

## TOP 버튼

화면 구석에 고정하지 않습니다. `body` 첫 자식인 `.to-top-rail`(sticky) 안의 버튼이 **오른쪽 중간(세로 50%)** 에 머물면서
스크롤할 때 살짝 따라 움직입니다(최대 ±8px, `prefers-reduced-motion` 이면 끔). 스크롤 420px을 넘으면 서서히 나타납니다.
- 넓은 화면(900px~): 본문 오른쪽 여백에 44px 원형 버튼
- 좁은 화면(~899px): 본문 글자를 가리지 않도록 오른쪽 가장자리의 얇은 세로 탭(26×84)

색·투명도·크기는 `.to-top` CSS 한 곳에서 바꾸면 두 페이지가 함께 바뀝니다(두 파일에 같은 코드가 들어 있습니다).
